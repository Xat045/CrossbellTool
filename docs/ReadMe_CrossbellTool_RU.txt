CrossbellTool 0.1 — разборка и сборка файлов Trails from Zero и Trails to Azure (PC)
  The Legend of Heroes: Trails from Zero   (zero.exe)
  The Legend of Heroes: Trails to Azure    (ao.exe)

ЧТО ДЕЛАЕТ
  Разбирает файлы из папки data игры или русификатора в обычные файлы для перевода (диалоги .json,
  таблицы .xlsx, картинки .png) и собирает правки обратно в файлы игры (.bin, ._dt, .itp) с той же
  структурой папок. Без правок файлы собираются байт-в-байт как оригинал.
  Сверка перевода — отдельная программа CrossbellCompare.exe.
  Нужна видеокарта с OpenGL 2 и выше.

──────────────────────────────── БЫСТРЫЙ СТАРТ

  1. «Папка игры или файлы» — папка игры или русификатора; берётся её папка data. Папку можно
     перетащить в окно.
  2. Откроется окно «Что разбирать» — отметьте нужное и нажмите «Готово».
  3. «Куда сохранять для правки» — папка проекта; «Куда сохранять собранное» — папка для результата.
  4. «Декомпилировать всё» → правьте файлы в папке проекта.
  5. «Собрать» → в окне «Что собрать» отметьте папки → «Собрать».
     Скопируйте собранное в папку data игры с заменой (оригиналы сохраните).

──────────────────────────────── ИГРА

  Определяется сама: zero.exe / ao.exe или «Zero» / «Azure» в имени папки. Справа над «Папка игры или файлы»
  видно, что определено; можно выбрать и вручную в списке «Игра». У каждой игры свои папки проекта
  и сборки; при первом запуске поля пустые — укажите папки сами.

──────────────────────────────── РАЗБОРКА

  Окно «Что разбирать» (открывается само после выбора папки; снова — кнопка «Файлы: N из M»):
  • папки data по разделам «Текст для перевода» и «Текстуры»: сколько сцен, таблиц, картинок,
    английские (._us) или японские файлы, размер;
  • по умолчанию отмечено всё; быстрый выбор: «Только текст», «Текст+текстуры», «Всё», «Снять всё»;
  • внизу — сколько займут разобранные файлы и примерно сколько времени (время — после первой
    разборки дольше 30 с на этом компьютере).
  Перед разборкой проверяется место на диске — если не хватает, программа предупредит.
  «Маска файлов» — только нужные файлы: c0100, t_town, c01. (через запятую; пусто — все).
  Уже изменённые вами файлы при повторной разборке не перезаписываются.
  Текстуры старого формата (с палитрой: модели, карты, монстры) пропускаются — текста в них нет.

  В папке проекта появятся:
    scena_us\..json — диалоги: переводите строки в "text"
                      (\n — новая строка в окне, {wait} — ждать нажатия; коды — раздел «Служебные коды» в ReadMe Сверки Zero/Azure);
    text_us\..xlsx  — таблицы (предметы, города, квесты, книги): правьте столбец B;
    ..png           — картинки (сохраняйте с прозрачностью, размер не меняйте).
    ..dds           — картинки, если при разборке выбран формат .dds: те же блоки BC7, что в .itp, без
                      перекодирования; при сборке переносятся в .itp как есть (сохранённые в другом
                      формате DDS — пережимаются, как .png). Правьте в редакторе с поддержкой DDS.

──────────────────────────────── СБОРКА

  Окно «Что собрать»: папки проекта и сколько файлов в каждой изменено; внизу — сколько примерно
  запишется и сколько займёт (время — после первой сборки дольше 10 с). Собираются только изменённые
  файлы отмеченных папок — обратно в .bin, ._dt и .itp, в «Куда сохранять собранное» с той же
  структурой (scena_us, text_us…).
  Надёжность:
  • перед сборкой проверяется место на диске;
  • если указать папку data игры или папку игры, программа спросит подтверждение;
  • файл пишется через временный: если запись не удалась, прежний файл (и файл игры) остаётся целым;
  • после записи каждый файл перечитывается, а сцены и таблицы разбираются обратно — файл, который
    игра не прочитала бы, сразу виден в журнале («✖») и в итоге «ошибок N»;
  • таблицы: если в Excel случайно перевели служебное имя (имя файла или модели — с «_»,
    например chr0000_c15), при сборке оно возвращается как в оригинале игры, в журнале — предупреждение.
    Числа не трогаются — их можно менять намеренно.

──────────────────────────────── ОКНО

  • Внизу вкладки «Справка» и «Журнал»; «Открыть проект», «Открыть собранное», «Стоп».
  • Долгая разборка или сборка (дольше 10 с) заканчивается уведомлением Windows со звуком,
    а кнопка программы на панели задач мигает.
  • Светлая и тёмная тема — кнопка внизу справа.

──────────────────────────────── ФАЙЛЫ РЯДОМ С ПРОГРАММОЙ

  CrossbellTool.ini — настройки (папки, маска, скорость разборки и сборки); CrossbellTool.log — журнал.

──────────────────────────────── КОМАНДНАЯ СТРОКА

  CrossbellTool decompile --game zero|azure --data <папка data> --proj <папка проекта>
                       [--types scena,tables,textures] [--mask ...] [--overwrite]
  CrossbellTool compile   --proj <папка проекта> --out <папка результата> [--data <папка data>] [--mask ...] [--all]
                       (--data — для сверки таблиц с оригиналом; --all — собрать всё, а не только изменённое)
  CrossbellTool file [--game zero|azure] <файл> — один файл: .bin/._dt/.itp → .json/.xlsx/.png и обратно
